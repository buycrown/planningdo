[LFmall 어필리에이트 - 로그인 화면]
인플루언서가 이메일 또는 휴대폰번호 + 비밀번호로 로그인하는 화면입니다.
로그인에 성공하면 활동내역 화면(03_활동내역/affiliate.html)으로 이동합니다.

- login.html      : 로그인 화면 (마크업만 · 이 파일을 열면 됩니다)
- index.html      : login.html 로 보내는 리다이렉트 문서  ★ 2026-08 신규
                    배포에서는 login.html 이 index.html 로 이름이 바뀝니다.
                    로컬에서 폴더를 index.html 로 열어도 로그인 화면이 뜨게 하는 용도입니다.
                    ⚠️ 배포 시 aff_login/index.html 은 'login.html 의 내용' 으로 올려야 합니다.
                       이 리다이렉트 문서를 그대로 올리면 login.html 이 없어 404 가 됩니다.
- css/login.css   : 화면 스타일 (화이트/블랙 미니멀 + 레드 포인트, 모바일 최적화)
- js/site-config.js : 공용 경로 모듈 (window.LFSite)  ★ 2026-08 신규
                    다른 폴더의 site-config.js 와 내용이 동일해야 합니다.
                    로그인 성공 후 이동할 활동내역 URL 도 이 모듈이 계산합니다.
- js/auth.js      : 공용 인증 모듈 (다른 폴더의 auth.js 와 내용이 동일해야 합니다)
- js/login.js     : 화면 동작 로직 (아이디 자동 판별, 비밀번호 토글, 로그인 요청, 세션 이동)
                    + 로그인 성공 직후 활동내역 데이터(userMe) 프리페치
                      → 활동내역 첫 진입에서 로딩(스켈레톤)을 보지 않게 합니다.
                      → 이동을 붙잡지 않으며, 실패해도 무시합니다(활동내역이 다시 부릅니다).
                      → 저장 위치는 sessionStorage['lf_affiliate_cache_v1'] 이며
                        키·형식은 js/auth.js 의 writeAffiliateCache 가 단독 관리합니다.
- lfmall-logo.png : 상단 로고 이미지

※ 위 파일들은 항상 같은 폴더 구조(css/ · js/) 그대로 함께 두어야 정상 동작합니다.
※ HTML 안에는 스크립트를 넣지 않았습니다. 동작 수정은 js/login.js 만 고치면 됩니다.
※ 스크립트 로드 순서 : js/site-config.js → js/auth.js → js/login.js
   ★ site-config.js 가 먼저여야 이동 경로가 환경에 맞게 계산됩니다.

[중요] 반드시 HTTPS 로 접속해야 로그인됩니다.
  비밀번호는 브라우저에서 PBKDF2 로 암호화한 뒤 전송하며, 이 기능(WebCrypto)은
  HTTPS 또는 http://localhost 에서만 동작합니다.
  login.html 파일을 더블클릭해서 여는 방식(file://)으로는 로그인이 되지 않습니다.
  → 로컬 확인 방법 : 이 폴더에서 python -m http.server 8000 실행 후
                     브라우저에서 http://localhost:8000/login.html 접속

[로그아웃/계정 전환 시 개인정보]
  로그아웃(clearSession) · 탈퇴 · 세션 만료 시 활동내역 캐시도 함께 지워집니다.
  다른 계정으로 로그인하면 캐시의 회원 id 가 다르므로 화면에 그리기 전에 폐기됩니다.
  (이전 계정 데이터가 한 프레임도 보이지 않습니다)
