서버 배포 상태

확인 방법
① 브라우저에서 웹앱 URL(/exec)에 접속해 (v2.0) 문구가 보이는지 확인
② Apps Script 편집기에서 apps-script.gs 최신본 반영 → initServer() 실행
③ 배포 관리 → 새 버전으로 재배포 후 이 화면을 새로고침

⚠️ initServer() 실행 전 DB 스프레드시트를 반드시 백업하세요. 1열 UUID → 순번 전환 · 헤더 개명 · 21~26열 백필은 되돌릴 수 없습니다. 구글 시트 [파일 → 사본 만들기] 로 백업본을 만들고 이름에 날짜를 남겨 주세요. 실행 후 반환 요약의 errors 가 비어 있고 rowsBefore 와 rowsAfter 가 같은지 확인합니다.
