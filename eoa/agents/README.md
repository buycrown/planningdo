# LFmall 온톨로지 분석 에이전트 시스템

매일 10:00 자동 갱신을 **1 Orchestrator + 3 전문 에이전트 + 1 비전 검수 에이전트**가 수행한다.
모든 에이전트는 공통 **5단계 사고 프로토콜**을 따른다.

## 공통 5단계 사고 프로토콜
1. **프로젝트 시작**: 구조 분석 → 코드베이스 탐색 → 프레임워크/라이브러리 파악 → 코딩 스타일·패턴 학습(UTF-8 BOM, 6축 체계, 기존 모듈 패턴).
2. **작업 계획**: 필요 컴포넌트 식별 → 구현 순서 결정 → 종속성 파악.
3. **실행**: 파일 생성/수정 → 코드 작성 → 패키지 설치 → 테스트 코드 작성·실행.
4. **검증·개선**: 테스트 → 오류 자동 수정 → 코딩 스타일·패턴 재학습.
5. **완료**: 산출물·설명서(MD) 생성 → Orchestrator 보고.

## 구성
- `orchestrator.md` — 조율자(작업 분해·전달·게이트)
- `analysis.md` — 분석(DB 적재·벡터화·온톨로지·연관규칙)
- `developer.md` — 개발(파이프라인/UI 코드, 파일 분리)
- `verifier.md` — 검증(테스트·오류 자동수정·스타일 점검)
- `vision_inspector.md` — AI 비전 검수(LFmall 페이지 직접 검수 → 소스 B)
- `product_ontology.md` — 상품 온톨로지(전 카탈로그 속성 + 동시구성 연관규칙 → 구성상품 추천, **별도 계층**)
