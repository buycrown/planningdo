# LFmall 인플루언서 어필리에이트 신청 화면 (POC)

어필리에이트 마케팅 참여를 원하는 인플루언서의 정보를 입력받아,
지정된 담당자 이메일로 신청 내용(첨부파일 포함)을 전송하는 화면입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 신청 화면 (로고 / 정보 입력 / 약관 동의) — 밝은 테마 |
| `app.js` | 화면 동작 로직 (SNS 다중 입력, 파일 첨부, 약관 검증, 전송) |
| `apps-script.gs` | 메일 발송 서버 코드 (Google Apps Script에 배포) |
| `README.md` | 본 문서 |

## 주요 기능

- **상단**: LFmall 로고 → 클릭 시 `m.lfmall.co.kr` 새 창 이동
- **중단**: 이메일 / 이름 / 활동명 / 관심 카테고리(복수 선택) / 휴대폰번호(자동 하이픈)
  - SNS 채널 다중 추가: Instagram · YouTube · X(Twitter) · TikTok 선택 시 채널 도메인 자동 기입
  - 파일 첨부: 여러 개 첨부 가능(총 용량 10MB 이하), 드래그&드롭 지원, 이메일 첨부파일로 전달
    (사업자등록 / 신분증 / 통장 사본 등 정산 서류 용도)
- **하단**: 약관 전체 동의 / 서비스 이용약관(필수) / 서비스 운영정책(필수)
  - '자세히 보기' 팝업 제공, 필수 약관 미동의 시 **신청하기 버튼 비활성화**
- **완료**: 전송 성공 시 완료 화면 노출

## 메일 전송 설정 (Google Apps Script)

현재 `app.js`의 `APPS_SCRIPT_URL`이 비어 있어 **데모 모드**로 동작합니다.
(신청하기 클릭 시 전송 데이터가 브라우저 콘솔(F12)에 출력됩니다.)

실제 메일 발송을 연결하려면 아래 순서로 1회만 설정하면 됩니다.

1. [script.google.com](https://script.google.com) 접속 → **새 프로젝트** 생성
2. 기본 코드를 지우고 `apps-script.gs` 내용 전체를 붙여넣기 → 저장
3. 우측 상단 **배포 → 새 배포** 클릭
   - 유형 선택(⚙️): **웹 앱**
   - 실행 계정: **나(자신의 구글 계정)**
   - 액세스 권한: **모든 사용자**
4. 배포 후 발급되는 **웹 앱 URL** 복사
   (`https://script.google.com/macros/s/…/exec` 형태)
5. `app.js` 상단 `CONFIG.APPS_SCRIPT_URL`에 붙여넣기 → 완료

> 첫 배포 시 구글 계정 권한 승인 창이 뜨면 허용해 주세요.
> 메일은 배포한 구글 계정 이름으로 발송됩니다.

## 수신자 추가/변경 방법

수신자는 두 곳 중 한 곳만 수정하면 됩니다.

- `app.js` → `CONFIG.RECIPIENTS` 배열 (기본: buycrown@lfcorp.com, yr.kwon@lfcorp.com)
- `apps-script.gs` → `DEFAULT_RECIPIENTS` 배열

배열에 `"이메일주소"`를 한 줄 추가하는 것만으로 수신자가 늘어납니다.
외부 악용이 걱정될 경우 `apps-script.gs`의 `ALLOW_CLIENT_RECIPIENTS`를
`false`로 바꾸면 서버(Apps Script)에 정의된 수신자 목록만 사용합니다.

## 메일이 오지 않을 때 점검 순서

1. **`app.js`의 `CONFIG.APPS_SCRIPT_URL`이 비어 있지 않은지 확인** ← 가장 흔한 원인
   - 비어 있으면 데모 모드로 동작하여 메일이 발송되지 않습니다. (콘솔 출력만 됨)
   - 신청하기 클릭 시 "데모 모드: …" 토스트가 뜬다면 이 상태입니다.
2. Apps Script 배포 설정 확인: **배포 → 배포 관리**에서
   - 실행 계정: **나** / 액세스 권한: **모든 사용자** 인지 확인
   - '모든 사용자'가 아니면 로그인 페이지가 응답되어 발송이 실패합니다.
3. `apps-script.gs` 코드를 수정했다면 **새 버전으로 재배포**해야 반영됩니다.
   (배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포)
4. 스팸함 확인 및 Apps Script 좌측 '실행' 메뉴에서 doPost 실행 기록/오류 확인
5. Gmail 무료 계정 1일 발송 한도(약 100건) 초과 여부 확인

## 참고 사항

- 약관 문안은 POC용 예시입니다. 정식 오픈 전 법무 검토 문안으로 교체가 필요합니다.
- Apps Script 무료 계정의 1일 메일 발송 한도(일반 Gmail 기준 약 100건/일)가 있으니,
  신청량이 많아지면 사내 SMTP/메일 API 연동으로 전환을 권장합니다.
- 화면은 모바일 우선(최대 폭 640px) 반응형으로 제작되었습니다.
