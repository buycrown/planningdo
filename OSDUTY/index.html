UI 컴포넌트

화면 권한과 별개로, 화면 안의 특정 버튼·필드를 켜고 끄는 단위입니다. 원본 표기: “권한 N : 컴포넌트 비활성화”. 상품(시트 상품_UI컴포넌트_290907)과 프로모션(시트 프로모션_UI컴포넌트, 프로모션_UI컴포넌트_명단)을 나누어 정리했습니다.

직무 × UI 컴포넌트 상관분석

“이 직무를 줄 때 어떤 컴포넌트를 같이 고민해야 하나?”에 답하기 위해, 실제 부여 명단에서 직무 보유자 중 해당 컴포넌트를 받은 비율을 계산했습니다. 셀을 클릭하면 근거가 된 사용자 명단이 열립니다.

NBOS 권한 → 원스피어 직무 전환 참고

시트 기존 직무 미매핑 대상과 오픈시 조회전용 삭제에 있는 “nbos 권한” 값을 기준으로, 기존 NBOS 권한 보유자에게 원스피어에서 어떤 직무·임시 직무·컴포넌트가 매핑되었는지 모았습니다. 신규 요청자가 기존 NBOS 권한을 알려줄 때 참고하세요.

사용자 명단

엑셀에 포함된 5개 명단을 그대로 조회할 수 있습니다. 기존 사용자의 부여 사례를 찾아 신규 계정 권한을 맞출 때 활용하세요.

검수 리포트
